# 🌐 Web Development Journey

Welcome to my Web Development learning repository!

This repository documents my journey as I learn modern web development from the ground up. Rather than simply following tutorials, I use this repository as a learning journal where I practice concepts, build projects, maintain revision notes, and become comfortable with Git and GitHub along the way.

## 🎯 Objectives

This repository serves three main purposes:

* 📖 Maintain concise revision notes for future reference.
* 🌱 Learn and practice Git & GitHub through regular commits and version control.

---

# 📚 Learning Roadmap

## Phase 1 — HTML

I began by learning the fundamentals of HTML.

Instead of writing isolated examples, I decided to build a **One Piece Fan Website**, gradually adding new features as I learned each topic. Every new HTML concept was immediately implemented into the website, allowing me to reinforce the concepts through practice.

Alongside the implementation, I maintain detailed notes in Markdown for quick revision.

---

## 🎨 Phase 2 — CSS

Once the HTML structure was complete, I moved on to CSS.

Rather than creating a separate project, I continued improving the same One Piece website by styling each newly added section using the CSS concepts I learned.

By the end of this phase, the website had evolved from a plain HTML page into a fully styled fan website.

---

## 💪 Practice Challenge

After completing the HTML & CSS sections, I wanted to test how much I had actually learned.

Instead of following another tutorial, I asked AI to generate **10 website design images**, arranged from easy to difficult.

For each challenge:

* I received only a reference image.
* I recreated the design entirely using HTML and CSS.
* My recreated webpage is placed alongside the reference image for comparison.

These challenges can be found in the **Practice Websites** directory.

---

## ⚡ Phase 3 — JavaScript

I am currently beginning my JavaScript journey.

The plan remains the same:

* Learn one concept at a time.
* Maintain concise revision notes.
* Immediately apply every new concept through mini-projects and interactive features.
* Track progress using Git commits.

---

# 🚀 Learning Philosophy

My goal is not just to finish tutorials, but to understand the concepts by building something with every topic I learn.

This repository is intended to be a chronological record of that journey—from writing my first HTML document to building increasingly complex web applications.

Every commit represents another small step forward.
